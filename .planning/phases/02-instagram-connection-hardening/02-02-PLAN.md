<objective>
Create proactive reconnect guidance when the Instagram token is expired or close to expiry.
</objective>

<tasks>

<task type="auto">
  <name>Sync token expiry notification</name>
  <behavior>
    - Check the authenticated user's `instagram_tokens.expires_at`.
    - Insert one active system alert if the token is expired or within the expiry window.
    - Update the existing active alert instead of creating duplicates.
    - Dismiss the active alert automatically when the token becomes healthy.
  </behavior>
</task>

</tasks>

<success_criteria>
- [x] Expired tokens create/update a "Token do Instagram expirou" alert.
- [x] Expiring tokens create/update a "Token do Instagram expira em breve" alert.
- [x] Healthy or missing tokens do not leave stale active expiry alerts.
</success_criteria>
